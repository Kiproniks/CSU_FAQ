# Ответ по базе знаний

Проект представляет собой систему вопросов и ответов по базе знаний. Пользователь задаёт вопрос, после чего система ищет подходящую информацию в документах и передаёт её языковой модели для формирования ответа.

В основе проекта используется подход **RAG (Retrieval-Augmented Generation)**.

## Как это работает

Сначала документы обрабатываются и разбиваются на небольшие фрагменты. После этого информация сохраняется в базе и становится доступной для поиска.

Когда пользователь задаёт вопрос:

1. система получает запрос;
2. выполняется поиск подходящей информации;
3. найденные фрагменты используются как контекст;
4. контекст вместе с вопросом передаётся языковой модели;
5. модель формирует итоговый ответ.

Таким образом, модель отвечает не только на основе своих знаний, а использует информацию из загруженной базы.

## Поиск

В проекте реализовано два варианта поиска.

### ChunkBased

В этом варианте документы разбиваются на отдельные chunks, после чего поиск выполняется среди этих фрагментов.

Это основной и наиболее простой вариант работы с базой знаний.

### EntityBased

В этом варианте при поиске дополнительно используются сущности, которые встречаются в документах.

Такой подход позволяет связывать информацию из разных частей документа и использовать её при формировании ответа.

## Используемые технологии

* Python
* PostgreSQL
* ChromaDB
* Ollama
* Qwen
* RAG
* векторный поиск

### PostgreSQL

Используется для хранения основной структурированной информации проекта.

### ChromaDB

Используется для хранения векторных представлений текста и выполнения семантического поиска.

### Ollama

Используется для запуска языковой модели локально.

В основном тестировании использовалась:

```text
qwen2.5:1.5b
```

Также тестировались другие модели:

```text
qwen2.5:0.5b
qwen3:8b
llama3.2:2b
```

## Оптимизация

Для ускорения обработки была добавлена пакетная обработка запросов.

В проекте есть отдельный режим:

```text
llm_fast_batched
```

Он позволяет обрабатывать несколько запросов за один цикл вместо последовательной обработки каждого запроса.

Также был реализован режим:

```text
llm_thought_chain
```

для другого варианта формирования ответа моделью.

## Установка

Клонировать репозиторий:

```bash
git clone <repository-url>
cd <project-directory>
```

Создать виртуальное окружение:

```bash
python -m venv venv
```

Активировать его в Windows:

```bash
venv\Scripts\activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Для работы LLM необходимо установить Ollama и загрузить модель:

```bash
ollama pull qwen2.5:1.5b
```

Также необходимо настроить подключение к PostgreSQL.

После настройки проект можно запустить:

```bash
python main.py
```

## Цель проекта

Основная цель проекта — разобраться на практике с RAG и попробовать собрать собственную систему вопросов и ответов по документам без использования внешних AI API.

Проект также позволил на практике поработать с векторными базами данных, семантическим поиском и локальными языковыми моделями.
