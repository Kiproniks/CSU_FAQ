# Поиск по документам для RAG

Учебный прототип для сравнения двух способов поиска контекста по текстовому запросу. На одном PDF можно посмотреть, какие фрагменты возвращают векторный поиск и поиск по словам. Проект реализует этап извлечения контекста для RAG; генерация ответа языковой моделью не входит в эту версию.

## Функциональность

- Извлечение текста из PDF с текстовым слоем в демонстрационном сценарии.
- Семантический поиск по фрагментам с перекрытием через ChromaDB.
- Поиск по TF-IDF с выделением частотных ключевых слов для каждого фрагмента.
- Сравнение результатов по одному запросу и визуализация характеристик фрагментов.

## Архитектура и проектирование

| Компонент | Индексация и поиск |
| --- | --- |
| [ChunkBased](ChunkBased/ChunkBased.py) | Нарезает текст на фрагменты с перекрытием, сохраняет эмбеддинги, текст и метаданные в локальной ChromaDB. |
| [EntityBased](EntityBased/EntityBased.py) | Принимает готовые фрагменты, хранит их с ключевыми словами в памяти и ранжирует по косинусному сходству TF-IDF. |

Интерфейс обоих модулей — классы Python. Метод `search(query, top_k)` возвращает пары «фрагмент, оценка». Оценки получены разными способами: сравнивать стоит порядок и содержание результатов, а не абсолютные значения.

## Технологии

Python, ChromaDB, Sentence Transformers (`all-MiniLM-L6-v2`), scikit-learn, NumPy, pypdf, Matplotlib, pytest.

## Запуск

Из корня репозитория в PowerShell (Python 3.12 и uv):

```powershell
uv venv --python 3.12 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt
$env:MPLBACKEND = "Agg"
.\.venv\Scripts\python.exe test/pdf_search_demo.py
.\.venv\Scripts\python.exe -m pytest -q
```

Демо использует [синтетический PDF](test/fixtures/faq-sample.pdf): печатает результаты обоих поисков и сохраняет два графика в PNG. При первом запуске векторного поиска нужен интернет для загрузки модели с Hugging Face. Индекс и графики создаются локально и исключены из Git.
