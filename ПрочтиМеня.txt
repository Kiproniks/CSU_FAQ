папка venv это окружение для проекта, чтобы установленные пакеты после удаления проекта не висели в памяти

чтобы ерейти в venv:
1/ открой терминал(главное, чтобы терминал существовал в корневой папке, если что есть dir, ls)
создаём окружение в корне проекта:
python -m venv .venv

2/ активируем окружение(делать каждый раз при запуске vsc):
# Windows:
.venv\Scripts\activate

# Mac / Linux:
source venv/bin/activate

после этого в терминале перед всеми текстами будет написано: (venv) ......

3/ нужно только если появились новые пакеты в файле requirements.txt или другого случая

установка пакетов:
pip install -r requirements.txt
